# 🤖 Techer — Discord Moderation Bot

> ⚠ **PROJETO DESCONTINUADO! (Discontinued Project)**

**Techer** é um bot de **moderação e segurança** desenvolvido especificamente para o **meu servidor privado**, com foco em controle administrativo, logs detalhados e proteção contra abusos.  
O código foi disponibilizado **publicamente** para que qualquer pessoa possa estudar, adaptar ou usar como base para seu próprio bot.

---

## ✨ Funcionalidades

### 🛡️ Moderação

- 🔨 Ban / Unban
- 👢 Kick
- 🔇 Timeout / Untimeout
- 🚔 Sistema de Prison (cargo)

### 📝 Logs

- Registro de todas as ações de moderação
- Logs no Discord e no banco de dados
- Geração de logs externos por link

### 🚨 Segurança

- Sistema **anti-raid / anti-abuso**
- Detecção de comportamentos suspeitos da staff
- Proteção contra ações em massa
- Bots ignorados automaticamente em verificações sensíveis

---

## ⚙️ Tecnologias

- **Node.js**
- **discord.js v14**
- **MongoDB / Mongoose**
- **Axios**
- **ms**

## 🔐 Objetivo

O objetivo do Techer é garantir **segurança**, **organização** e **transparência** dentro do servidor, evitando abusos administrativos e protegendo o servidor contra ataques ou ações maliciosas.
